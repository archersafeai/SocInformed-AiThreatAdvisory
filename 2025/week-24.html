Week 24: Jun 9, 2025 – Jun 15, 2025

2 real, sourced AI-security events identified this week — 2 Critical, 0 High.

EchoLeak: first documented zero-click prompt injection in a production LLM system

Critical
June 2025

Aim Security disclosed EchoLeak (CVE-2025-32711, CVSS 9.3), a zero-click vulnerability in Microsoft 365 Copilot. A single crafted email, with no user interaction required, could plant instructions that Copilot later executed when a user asked an unrelated routine question, exfiltrating content from OneDrive, SharePoint, and Teams to an attacker-controlled destination. Microsoft patched the issue.

Source: Aim Security / NIST NVD, June 2025 — https://www.mdpi.com/2078-2489/17/1/54

CamoLeak: GitHub Copilot Chat silent code exfiltration (CVSS 9.6)

Critical
found June 2025; GitHub fix Aug 14, 2025; publicly disclosed October 2025

Researcher Omer Mayraz (Legit Security) found that hidden HTML comments in GitHub pull-request descriptions could inject prompts into Copilot Chat, exfiltrating data through pre-signed GitHub Camo proxy image URLs that bypass Content-Security-Policy. Private source code, API keys, and undisclosed vulnerability details could be extracted from organizational repositories. GitHub disabled image rendering in Copilot Chat as a mitigation.

Source: Legit Security / Rafter AI Agent Security Timeline — https://rafter.so/blog/incidents/ai-agent-security-timeline-2025-2026
